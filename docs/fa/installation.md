# راهنمای نصب (برنامه‌ریزی‌شده — فاز ۱ به بعد)

> این راهنما مسیر **مورد نظر** نصب رو توصیف می‌کنه، برای وقتی که Add-in سالیدورک (فاز ۱) ساخته بشه. الان، قبل از پیاده‌سازی، نوشته شده تا فاز ۱ یه هدف مشخص برای ساختن داشته باشه. فعلاً هیچ‌چیز تو این راهنما قابل‌نصب نیست — به [نقشه‌راه](../../README_FA.md#-نقشه-راه) برای وضعیت فعلی نگاه کنید.

## مرحله ۱ — پیش‌نیازها

- یک نسخه‌ی پشتیبانی‌شده از SolidWorks (بعد از شروع توسعه‌ی فاز ۱ روی یه نسخه‌ی مشخص از SDK قفل می‌شه)
- Visual Studio 2022 (برای build کردن Add-in از سورس)
- .NET Framework (نسخه‌اش با SolidWorks API SDK هماهنگ می‌شه)
- نصب [Ollama](https://ollama.com) برای حالت آفلاین
- کلید API از OpenAI، Anthropic یا Google برای حالت آنلاین

## مرحله ۲ — دریافت پروژه

```bash
git clone https://github.com/aminetemadkian-stack/AI-SolidWorks-Assistant.git
cd AI-SolidWorks-Assistant
```

تازه با Git کار می‌کنید؟ [راهنمای رسمی گیت‌هاب](https://docs.github.com/en/get-started/quickstart) نقطه‌ی شروع خوبیه.

## مرحله ۳ — تنظیمات AI

- حالت آنلاین: کلید API خودتون (GPT / Claude / Gemini) رو تنظیم کنید (روش دقیقش تو فاز ۳ مشخص می‌شه — احتمالاً متغیر محیطی یا فایل تنظیمات، هرگز داخل ریپو commit نمی‌شه).
- حالت آفلاین: دستیار رو به نصب محلی Ollama و مدل انتخابی‌تون (Qwen، DeepSeek و...) وصل کنید.
- یک حالت انتخاب کنید: **اول آنلاین** (پیش‌فرض، خودکار به آفلاین برمی‌گرده) یا **فقط آفلاین**.

## مرحله ۴ — Build پروژه

- Solution رو در Visual Studio 2022 باز کنید.
- پروژه‌ی Add-in رو build کنید.
- Add-in رو در SolidWorks ثبت کنید (ثبت COM — جزئیات دقیق بعد از ساخته‌شدن `SolidWorks_Addin/` مستند می‌شه).

## مرحله ۵ — اولین اجرا

- SolidWorks رو با Add-in فعال باز کنید.
- پنل AI رو باز کنید.
- یه دستور اول امتحان کنید، مثلاً:

  > «یک مکعب ۱۰۰ میلی‌متری بساز.»

## مرحله ۶ — رفع خطا

به [troubleshooting.md](troubleshooting.md) بعد از رسیدن فاز ۱ نگاه کنید. پوشش برنامه‌ریزی‌شده: مشکلات نصب، مشکلات اتصال API، مشکلات ثبت Add-in سالیدورک، مشکلات Ollama، و خطاهای رایج.
