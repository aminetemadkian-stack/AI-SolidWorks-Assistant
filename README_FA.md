# دستیار هوش مصنوعی سالیدورک

یک دستیار هوش مصنوعی که داخل **SolidWorks** نصب می‌شود و زبان طبیعی (فارسی و انگلیسی، زبان‌های بیشتر در آینده) را به عملیات واقعی CAD — اسکچ، فیچر، اسمبلی و نقشه — تبدیل می‌کند، از طریق یک مسیر فرمان امن و قابل‌ردیابی.

> ⚠️ **وضعیت فعلی: فاز ۰ — پایه‌گذاری.** این مخزن فعلاً فقط شامل اسکلت پروژه، معماری و نقشه‌راه است. پیاده‌سازی واقعی Add-in و هسته‌ی AI هنوز ساخته نشده — به [نقشه‌راه](#-نقشه-راه) نگاه کنید تا ببینید هرکدوم کِی و به چه ترتیبی میان.

### اصل کلیدی طراحی

AI **هرگز** کد دلخواه روی مدل SolidWorks شما اجرا نمی‌کنه. فقط یک فرمان ساختاریافته تولید می‌کنه (مثلاً `operation=hole, diameter=10mm, position=center`) که قبل از رسیدن به موتور فرمان — تنها لایه‌ای که اجازه‌ی تماس با SolidWorks API رو داره — اعتبارسنجی می‌شه.

```
AI  →  تصمیم‌گیری و برنامه‌ریزی
 │
 ▼
مفسر CAD  →  زبان طبیعی به فرمان ساختاریافته
 │
 ▼
موتور فرمان  →  عملیات استاندارد و اعتبارسنجی‌شده‌ی CAD
 │
 ▼
SolidWorks API  →  تنها لایه‌ای که با SolidWorks تماس داره
 │
 ▼
SolidWorks
```

این جداسازی یعنی بعداً می‌شه مدل AI، provider ابری، یا مدل محلی رو عوض کرد بدون این‌که لازم باشه اتصال SolidWorks از نو نوشته بشه.

### مسیر AI: اول آنلاین، در نبود اینترنت آفلاین

```
AI ابری
   │
   ├── موفق → استفاده می‌شه
   │
   └── ناموفق
        ↓
     Ollama (محلی)
```

کاربر لازم نیست دستی چیزی رو عوض کنه — اگه اینترنت نباشه یا تماس ابری شکست بخوره، دستیار خودکار میره سراغ مدل محلی Ollama.

## 🗺️ نقشه‌راه

| فاز | هدف | Milestone |
|---|---|---|
| ۰ | پایه‌گذاری پروژه — ریپو، مستندات، معماری | همین مخزن با همین مستندات |
| ۱ | پایه‌ی Add-in سالیدورک | Add-in داخل SolidWorks با یک پنل AI باز می‌شه |
| ۲ | هسته‌ی AI (کنترلر، روتر، مدیریت زمینه، اعتبارسنج) | خط‌لوله‌ی هسته وجود داره، هنوز به CAD وصل نیست |
| ۳ | AI آنلاین (اولین provider ابری) | یک درخواست ابری یک فرمان ساختاریافته تولید می‌کنه |
| ۴ | AI آفلاین (Ollama) | دستیار بدون اینترنت هم کار می‌کنه |
| ۵ | هوش مصنوعی مهندسی فارسی | فرمان فارسی (محاوره و رسمی)، واحدها، جمله‌ی ترکیبی فارسی+انگلیسی |
| ۶ | موتور فرمان CAD | Sketch، Extrude، Cut، Hole، Fillet، Chamfer، Pattern، Mirror |
| ۷ | مدل‌سازی هوشمند | دستیار تغییرات رو پیشنهاد می‌ده برای تأیید، نه فقط اجرای فرمان |
| ۸ | هوش اسمبلی | درج قطعات، Mate، آگاهی از تداخل/برخورد |
| ۹ | نقشه و ساخت | نقشه، BOM، اندازه‌گذاری، محدودیت‌های ساخت |
| ۱۰ | هوش مهندسی | پیشنهاد بهینه‌سازی — هرگز بدون محاسبه/شبیه‌سازی واقعی به‌عنوان تحلیل معتبر ارائه نمی‌شه |
| ۱۱ | امنیت و پایداری | مجوزها، اعتبارسنجی فرمان، sandbox، لاگ، امنیت API key |
| ۱۲ | انتشار عمومی v1.0.0 | کد کامل، مستندات، مثال، تست، راهنمای نصب به ۱۰ زبان |
